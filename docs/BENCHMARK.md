# 인용 검증 벤치마크

법령 도구가 "우리도 검증한다"고 말하는 것은 쉽다. 검증한다는 말이 무엇을 뜻하는지 정의하고,
그 정의를 재현 가능한 실행으로 고정하는 것은 어렵다. 이 문서가 그 정의다.

fin-law-mcp의 인용 검증(`fin_verify`)은 두 방향 모두에서 평가된다.

| 방향 | 뜻 | 실무 피해 |
| --- | --- | --- |
| **거짓 음성** | 실존하지 않는 인용에 ✓를 준다 | 검토서에 없는 조문이 근거로 남는다. **가장 심각하다** |
| **거짓 양성** | 실존하는 인용에 ✗·⚠를 준다 | 실무자가 맞는 근거를 지운다 |
| **조용한 누락** | 인용을 추출조차 못 해 판정 없이 넘어간다 | 검증했다고 믿지만 실제로는 안 했다 |

세 가지를 한꺼번에 잡아야 한다. 한 방향만 막으면 다른 방향이 무너진다 —
실제로 이 저장소에서 "누락(안전)을 고치려다 오검증(위험)을 만든" 사고가 있었다 (아래 표 6번).

---

## 1. 게이트 정의

### 게이트 A — 정상 인용 20문장 (거짓 양성 차단)

재무 도메인의 **실존하는** 인용 20문장을 넣어 **25개 인용이 전부 ✓**로 판정되어야 한다.
✗은 물론이고 ⚠도 통과가 아니다. ⚠는 "없음"이 아니라 "판정 불가"(조회 실패·DB 미수록·기준일 미적용 등 —
사유는 판정 줄마다 다르다)지만, 실무자에게는 "이 근거는 아직 못 믿겠다"와 같은 뜻이기 때문이다.

20문장은 재무 스펙트럼과 표기 변형을 함께 덮는다.

- **법령**: 법인세법·소득세법·부가가치세법·상속세 및 증여세법·조세특례제한법·근로자퇴직급여 보장법·주식회사 등의 외부감사에 관한 법률·국세기본법·상법·관세법·「외국환거래규정」(기재부 고시)
- **종류**: 본법 / 시행령 / 시행규칙 / 행정규칙
- **표기**: `「」` 인용부호, 접속사(`및`), 가지조문(`제19조의2`), 공백이 든 정식 명칭, 40자급 긴 정식 명칭
- **조응**: `같은 법`, `같은 법 시행령`, `동 시행령`
- **약칭**: 부가세법·상증법·조특법·근퇴법·외감법

인용 **추출 개수**도 같이 검사한다. 판정이 전부 ✓여도 인용 하나가 추출되지 않았다면
그것은 조용한 누락이고, 게이트 실패다.

### 게이트 B — 오검증 회귀 (거짓 음성 차단)

3절의 회귀 사례 중 테스트로 박제된 것이 `npm test`에서 통과해야 한다. 83건 중 77건은 "박제" 칸이 테스트 파일이고,
6건(#36·38·48·51·52·69)은 테스트가 아니라 소스 코드·훅 스크립트·문서 위치가 적혀 있다 — 이 6건은 표만으로 `npm test`가 지킨다고 말할 수 없다.
이 사례들은 전부 **실제로 이 저장소에서 발생했던 결함**이며, 대부분 실 API 응답으로 재현·확인한 것이다.

## 2. 재현 방법

```bash
# 게이트 A — 실 법제처 API 호출 (LAW_OC 필요)
npm run build
node scripts/gate20.mjs

# 게이트 B — 실 API 불필요, CI 상시
npm test

# 골든셋 (조문 잘림·별표 값 대조) — 실 API
npm run test:live
```

`scripts/gate20.mjs`는 문장 사이를 기본 6초 띄운다. 법제처 분당 한도(30회)에 걸리면
정상 인용도 ⚠로 나오기 때문이다. **이 ⚠는 결함이 아니라 측정 잡음이다** —
러너는 ⚠·✗ 문장을 1회 재시도하고, 사유가 한도·타임아웃이면 그렇게 표기한다.
다른 작업과 API 키를 공유 중이라면 `GATE_INTERVAL_MS=10000`처럼 간격을 늘려 재실행하라.

## 3. 오검증 회귀 사례

각 행은 "틀린 인용에 ✓를 주거나, 맞는 인용에 ✗를 주던" 실제 결함이다.
"박제" 칸이 테스트 파일인 행은 되살아나면 `npm test`가 깨진다. 소스·스크립트·문서 위치만 적힌 행
(#36·38·48·51·52·69)은 테스트 박제로 표기되어 있지 않다.

## 5. 이 벤치마크를 재사용하려면

`scripts/gate20.mjs`의 `SENTENCES` 배열이 게이트의 전부다. 문장을 바꾸려면
**인용의 실존을 먼저 확인하라** — 실존하지 않는 문장을 넣으면 게이트가 거꾸로 돌아간다.

다른 도메인(노동·공정거래·건설)으로 옮길 때는 그 도메인의 정상 인용 20문장을 같은 형식으로
작성하면 된다. 조응·약칭·`「」` 표기·시행령/시행규칙을 섞는 것이 핵심이다 —
결함은 대개 평범한 `법령명 + 제N조`가 아니라 이 변형들에서 나온다.
