# fin-law-mcp

**재무·회계·세무·자금 실무 특화 한국 법령 MCP 서버.**
AI가 세무 답변의 '해설'을 하는 시대에, 이 서버는 그 해설이 맞는지 확인할 **검증 가능한 원천 근거 파이프**를 제공합니다 — 조문·예규·심판례·판례를 문서번호와 출처까지 갖춘 형태로, 오류를 절대 "없음"으로 위장하지 않으면서.

> 범용 법령 MCP와 다른 점: 세법은 "법률–시행령–시행규칙 3단 + 예규"가 한 세트입니다.
> 이 서버는 그 세트를 알고 묶어서 답합니다. 조문 하나를 물으면 위임 시행령 본문과
> 관련 예규까지 **1회 호출**로 옵니다 (범용 MCP 기준 5~6회 호출 분량).

## 도구 (7개)

| 도구 | 하는 일 |
|------|------|
| `fin_article` | 조문 + 위임 시행령·시행규칙 **본문** + 관련 예규 + 별표 + **시행예정 개정 경고**를 1회 응답으로 |
| `fin_law_search` | 법령 검색 → 재무 관련도순 재정렬 (부분매칭 함정 방어 · 폐지/연혁/시행예정 표시 · 주제어→법령 힌트) |
| `fin_ruling_search` | 국세청 예규 + 조세심판원 + 법제처 해석례 + 대법원 판례를 한 번에, **최신순** + 전거 서열 표기 |
| `fin_nts_ruling` | 국세청 예규 검색 + 상위 건 **본문 전문** 자동 동봉 (문서번호·회신일자 포함) |
| `fin_annex` | 별표·서식 목록 + 다운로드 링크 (감가상각 내용연수표·세율표) |
| `fin_verify` | 초안의 법령·조문·고시 인용을 실존 검증 — **✓있음/✗없음/⚠판정불가 3값** |
| `fin_calc` | 법정 산식 결정형 계산 (임원퇴직금 한도·기업업무추진비 한도) — LLM 산수 배제, 계산 과정·근거 조문 동봉 |

## 신뢰 원칙 (이 서버의 존재 이유)

세무 검토에서 최악의 실패는 오답이 아니라 **"조용한 실패"** — 오류가 "0건"으로 위장되어 "그런 예규 없음"이라는 잘못된 단정이 검토서에 실리는 것입니다. 이 서버의 규율:

1. **3값 판정**: "못 찾음(✗)"과 "확인 실패(⚠)"를 절대 같은 값으로 반환하지 않는다. 네트워크 오류·한도 초과는 전부 ⚠.
2. **근거 동봉**: 모든 답에 문서번호(`법인세과-352` 형식)·일자·출처 URL — 복사해서 바로 인용 가능한 형태로.
3. **전거 서열 표기**: 법령 조문 > 판례 > 심판례·유권해석 > 예규(행정해석). 예규를 확정 근거처럼 오용하지 않도록 매 응답에 명시.
4. **개정 경고**: 이미 공포된 미래 시행 개정을 감지해 경고 ("이 법은 2027-01-01 시행 개정이 공포되어 있음").
5. **골든셋 회귀**: 실제 사고 사례(조문 목 45개 절단, 429가 0건으로 표시 등)가 테스트로 박제되어 있다.
6. **부분 실패 계약**: 묶음 응답의 한 섹션이 실패해도 나머지는 살리고, 실패 사유를 그 자리에 명시한다.

## 설치

```bash
git clone <repo> && cd fin-law-mcp
npm install && npm run build
```

1. [법제처 OPEN API](https://open.law.go.kr/LSO/openApi/guideResult.do) 키 발급 (무료 — 가입 이메일 @ 앞부분이 키)
2. `.env` 파일 생성: `LAW_OC=발급받은키`
3. 등록:
   - Claude Code: `claude mcp add fin-law node /절대경로/fin-law-mcp/build/index.js`
   - Claude Desktop: `claude_desktop_config.json`의 `mcpServers`에 추가

```jsonc
{
  "mcpServers": {
    "fin-law": { "command": "node", "args": ["/절대경로/fin-law-mcp/build/index.js"] }
  }
}
```

## 환경변수

| 변수 | 설명 |
|------|------|
| `LAW_OC` | 법제처 OPEN API 키 (필수) |
| `FIN_NTS_BODY_ENABLED` | 국세청 예규 본문 조회 (기본 on — `false`로 목록만) |
| `FIN_NTS_BODY_TOP_N` | 예규 본문 자동 동봉 건수 (기본 2, 최대 5) |
| `LAW_API_PROTOCOL` / `LAW_RESPONSE_TYPE` | 폐쇄망 http 전환 / XML 장애 시 JSON 우회 |

## 알아둘 것

- **국세청 예규 본문**은 국세법령정보시스템의 공식 API가 아닌 내부 경로로 조회합니다. 사이트 개편 시 중단될 수 있으며, 그 경우 목록+원문 링크로 자동 강등됩니다 (조용히 사라지지 않습니다).
- `fin_calc`의 산식에는 **기준 시행일이 명시**됩니다. 세법은 매년 개정되므로 중요한 판단 전에 `fin_article`로 현행 조문과 교차 확인하세요.
- 이 도구의 출력은 참고용입니다. **법적 효력이 필요한 판단에는 반드시 국가법령정보센터 원문을 확인하세요.**
